## 目标
在固定的审计 agent、固定的历史 replay world 上，最大化回放目标：

    V = 归一化质量-成本 hypervolume

质量来自已确认漏洞（TP / CVE Tier）；FP、design、duplicate 会扣分。成本是 agent calls。

## 你只能改 exploration policy
- 不能改审计 agent、不能改 evaluator、不能改历史。
- 只能决定每一轮从 `obs.eligible` 里选哪些候选节点，最多 `obs.max_workers` 个。
- 候选节点在 reveal 之前只能看到 label/scope/skill/tags/prior_severity/depth，不能看到 outcome。
- 已 reveal 的节点可以看到 outcome。

## 可用 API
```python
class Policy(BasePolicy):
    name = "dreamed-..."

    def select(self, obs):
        return self.pick(obs, self.rank_evidence)
```

`BasePolicy` 已提供：
- `self.pick(obs, key)`：按 key 从高到低排序，取前 `obs.max_workers` 个。
- `self.tag_hits(view)` / `self.low_yield_hits(view)` / `self.kind_rank(view)` / `self.severity_rank(view)`
- `self.rank_baseline` / `rank_breadth` / `rank_depth` / `rank_evidence` / `rank_cve` / `rank_precision`
- `obs.eligible: tuple[str, ...]`
- `obs.nodes: dict[str, NodeView]`
- `obs.rho`, `obs.rounds`, `obs.spent`, `obs.best_score`, `obs.max_workers`
- `NodeView` 字段：`id, parent_id, kind, label, scope, skill, hypothesis, tags, prior_severity, depth, index, cost, revealed, outcome`
