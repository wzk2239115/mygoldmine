# 共享挖掘经验

本技能保存通过真实前后运行评估的共享修复。规则位于 `rules/`，索引位于 `rules/index.json`。

## 使用顺序

1. 先读取 `rules/index.json`，按当前候选问题的类别、根因和防护条件选择相关规则，不要一次加载全部历史。
2. 同时检查 `$MYGOLDMINE_HOME/knowledge/project-rules/<project>/index.json`；项目规则只用于对应项目，与共享规则冲突时先核对当前代码证据，不得自动互相覆盖。
3. 误报排除规则只有在根因、可达性前提和反证一致时才生效。不得只按类别、危险函数或文件名称排除。
4. 已确认调查模式只用于安排调查顺序，不得直接继承此前的漏洞结论。
5. 当前代码、默认配置或信任边界已经变化时，将旧规则标为待复核并重新验证。

挖掘入口也会注入当前已发布规则的上下文；注入内容超过预算时，必须按提供的来源文件路径继续读取，不能忽略项目专属规则。
