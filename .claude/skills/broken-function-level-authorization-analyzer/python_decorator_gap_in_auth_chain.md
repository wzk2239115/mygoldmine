# Python｜权限装饰器链存在缺口

## Details

### 漏洞成因
Python Web 框架常通过装饰器链实现认证与授权。例如 `@login_required` + `@permission_required`。若在路由注册时忘记添加关键装饰器，或装饰器顺序/条件判断导致某些分支跳过权限校验，就会造成函数级授权缺失。常见于蓝图/Blueprint、视图类继承、动态路由注册时遗漏授权装饰器。

### 代码示例

**易受攻击示例：**
```python
# 期望所有 admin 路由都使用 admin_required
admin_blueprint = Blueprint('admin', __name__)

@admin_blueprint.route('/users/create', methods=['POST'])
@login_required
def create_user():
    # 忘记附加 @admin_required
    create_user_from_form(request.form)
    return 'OK'
```

**安全示例：**
```python
@admin_blueprint.route('/users/create', methods=['POST'])
@login_required
@admin_required
def create_user():
    create_user_from_form(request.form)
    return 'OK'
```

### 快速定位技巧

#### 核心操作定位（审计等级：L1-L2）
**关键词扫描：** `@login_required`, `@permission_required`, `@admin_required`, `bp.route`, `add_url_rule`, `dispatch_request`。

**定位步骤：**
1. 列出所有敏感路由或视图函数；
2. 跳读（L2）确认装饰器链是否包含权限装饰器；
3. 注意 `add_url_rule` 动态注册时是否传入 `view_func` 包含装饰器。

#### 保护机制定位（审计等级：L2-L3）
**检查是否存在：**
- 蓝图/类视图基类统一装饰；
- 中间件层进行 RBAC；
- Decorator 内部调用权限模块；
- 单元测试覆盖权限场景。

**定位技巧：**
- 逐行读（L3）装饰器实现，确认在未满足条件时是否继续调用下一个；
- 跨模块追踪（L4）不同蓝图/路由文件是否重复注册导致遗漏。

#### 审计等级标注
| 场景 | 审计等级 | 说明 |
|------|----------|------|
| 全局中间件强制权限校验 | **L0（快速跳过）** | 安全性高 |
| 大部分路由正确装饰，少量疑似遗漏 | **L2（跳读）** | 快速确认 |
| 装饰器链存在缺口 | **L3（逐行读）** | 高风险 |
| 动态路由或外部模块绕过装饰器 | **L4（跨模块追踪）** | 全链路审计 |

## Classify

### 研判标准

#### 确认漏洞
1. 特定路由缺少权限装饰器；
2. 普通用户可访问管理员功能；
3. 漏洞可复现并影响敏感操作。

#### 误报
1. 路由经过中间件拦截器强制授权；
2. 视图函数内部调用权限检查并拒绝未授权请求；
3. 路由仅在开发测试环境启用。

#### 代码异味
1. 装饰器链逻辑复杂（条件判断、早返回），易出错；
2. 靠代码生成或自动注册但未验证权限；
3. 缺乏测试覆盖导致遗漏不可见。

## Low risk

### 低风险评级场景

#### 1. 功能仅影响非敏感数据
- **场景：** 仅修改个人偏好；
- **评估：** 可标低风险。

#### 2. 内部运维接口
- **场景：** 仅运维人员在受控环境使用；
- **评估：** 攻击面有限。

#### 3. 即将统一装饰器校验
- **场景：** 已计划改造为全局权限中间件；
- **评估：** 可暂降级，跟踪执行。

#### 风险降级条件总结
| 条件 | 降级理由 | 建议优先级 |
|------|----------|------------|
| 非敏感功能 | 影响有限 | 低 |
| 受控环境 | 攻击面小 | 中 |
| 改造计划明确 | 可暂缓 | 低 |
