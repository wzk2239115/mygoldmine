# PHP 搜索关键词反射型 XSS

## 基本信息

- **难度等级：** ★★☆☆☆ (初级)
- **审计时间：** 10-20分钟（单个漏洞点）
- **先决知识：** PHP 超全局变量（$_GET、$_POST）、htmlspecialchars()、表单处理
- **复杂度评估：**
  - 简单场景（单点反射）：10-15分钟
  - 复杂场景（多层参数、动态 SQL）：20-30分钟

## 🚀 30秒快速清单

- [ ] 代码是否直接使用 `$_GET`、`$_POST` 或 `$_REQUEST` 等超全局变量？
- [ ] 这些变量是否直接输出到 HTML 中（如 `echo $_GET['keyword']`）？
- [ ] 输出前是否使用了 `htmlspecialchars()`、`htmlentities()` 或其他编码函数？
- [ ] 是否存在对输入的验证或白名单检查？
- [ ] 搜索结果页面的错误信息是否也进行了安全编码？

**判断：** 如果第 1-2 个问题打勾且第 3 个未打勾，需要进行 L2+ 深度分析

## Details

### 漏洞成因
搜索、筛选等功能通常会把用户输入的关键词回显到页面（提示“您搜索了 XXX”）。若未对关键词进行 HTML 实体编码，就会形成反射型 XSS。攻击者构造包含脚本的 URL，诱导受害者点击，即可执行恶意代码。

### 代码示例

**易受攻击的代码：**
```php
$query = $_GET['q'] ?? '';
$results = searchArticles($query);
?>
<h2>搜索结果：<?php echo $query; ?></h2>
<ul>
<?php foreach ($results as $row): ?>
  <li><?php echo $row['title']; ?></li>
<?php endforeach; ?>
</ul>
<?php
```

**安全示例：**
```php
$query = $_GET['q'] ?? '';
$safeQuery = htmlspecialchars($query, ENT_QUOTES, 'UTF-8');
?>
<h2>搜索结果：<?php echo $safeQuery; ?></h2>
<?php
```

### 快速定位技巧

#### 核心操作定位（审计等级：L1-L2）
**关键词扫描：** `$_GET`, `$_POST`, `$_REQUEST`, `search`, `keyword`, `query`, `echo`。

**定位步骤：**
1. 搜索输出搜索关键词的模板；
2. 跳读（L2）确认是否使用 `htmlspecialchars`；
3. 检查是否将关键词拼接到其他 HTML 片段或属性中。

#### 保护机制定位（审计等级：L2-L3）
**检查是否存在：**
- 全局输出编码辅助函数；
- 使用模板引擎自动转义；
- 对关键词进行白名单限制或长度限制；
- 统一的搜索组件封装。

**定位技巧：**
- 逐行读（L3）处理流程，确认特殊字符处理正确；
- 跨模块追踪（L4）关键词是否传递给其他页面或日志。

#### 审计等级标注
| 场景 | 审计等级 | 说明 |
|------|----------|------|
| 所有输出均调用转义函数 | **L0（快速跳过）** | 风险低 |
| 个别回显遗漏编码 | **L2（跳读）** | 快速修补 |
| 直接将参数拼接到 HTML | **L3（逐行读）** | 高风险 |
| 关键词传递跨模块 | **L4（跨模块追踪）** | 需完整数据流 |

## Classify

### 研判标准

#### 确认漏洞
1. 搜索关键词未编码直接输出；
2. 可通过 URL 注入脚本；
3. 受害者访问后脚本执行。

#### 误报
1. 搜索词已编码或仅用于后端逻辑；
2. 页面仅在内网测试环境使用；
3. 搜索词通过严格白名单（仅字母数字）。

#### 代码异味
1. 仅用 `strip_tags` 等不充分过滤；
2. 在 HTML 属性、脚本上下文拼接关键词；
3. 缺少统一处理函数，多处复制粘贴。

## Low risk

### 低风险评级场景

#### 1. 页面仅面向内部用户
- 可暂记低风险，但仍需修复。

#### 2. 搜索功能只允许严格的白名单字符
- XSS 难度大，但仍建议编码。

#### 3. 已计划引入统一模板编码
- 明确排期，可暂降级并跟踪。

### 风险降级条件总结
| 条件 | 降级理由 | 建议优先级 |
|------|----------|------------|
| 内部页面 | 攻击面小 | 中 |
| 严格白名单 | 触发难度高 | 低 |
| 改造计划明确 | 可暂缓 | 低 |
