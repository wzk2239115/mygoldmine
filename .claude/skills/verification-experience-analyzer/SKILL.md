# 验证经验分析

## 输入

蓝队验证报告、红队运行与独立审核、人工结论、候选问题根因和发现记录。

## 分析步骤

1. 按候选问题关联蓝队与红队证据，不把同一次静态推测当成两个独立证据。
2. 区分实际运行、独立审核、人工结论、静态证据、未知和环境受阻。
3. 误报必须提取实际反证：默认配置、可达性、认证、受信输入、安全加载或防护逻辑。
4. 已确认问题提取可复用调查路径：入口、信任边界、危险操作、必要前提和最小验证方式。
5. 红队未捕获或环境受阻不等于误报；静态相似不等于已确认。

## 输出

向学习智能体提供按候选问题整理的经验摘要：结论、证据等级、根因、反证、可复用动作和失效条件。只提供证据，不生成发布结论。
