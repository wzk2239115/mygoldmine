# PHP_Crypto_Integer_Overflow

**漏洞类型**: 哈希或加密算法中的整数溢出，自定义加密算法中的数值计算

## Details

**代码示例**：自定义哈希函数中的模运算、密钥生成中的位运算、`random_int()` 参数溢出

- **核心操作定位技巧** (L2: 跳读)：扫描自定义加密/哈希算法实现，特别关注模运算（`%`）、位运算（`<<`、`&`、`|`）、以及大整数运算。检查 `random_int()`、`openssl_random_pseudo_bytes()` 等随机数生成函数的参数。重点审计非标准库实现的密码学操作。

- **保护机制定位技巧** (L3: 逐行读)：查找使用标准库（`password_hash`、`hash_hmac`、`openssl_*`）代替自定义实现、使用 GMP 扩展处理大整数、或对所有密码学参数进行严格验证。检查是否有密码学审计注释。

## Classify

判断是否为漏洞的要点：
- **确定漏洞**：自定义密码学算法中存在整数溢出，可能导致密钥弱化、哈希碰撞或安全性降低
- **误报**：使用成熟的密码学库、有专业审计、溢出不影响安全性
- **代码异味**：存在自定义密码学实现，需专业审计

## 审计技巧与经验分享

### 真实漏洞识别模式

**1. 密钥生成中的整数溢出**
- 关键特征：在 `random_int()` 或位运算中，min/max 参数超过 PHP_INT_MAX 或使用无符号整数扩展
- 真实案例：`random_int(0, 0xFFFFFFFF)` 在 32 位系统上溢出，导致生成的密钥范围不符预期
- 审计要点：检查是否验证了参数范围，是否考虑了平台差异（32/64 位）

**2. 模运算链中的溢出累积**
- 关键特征：多个算术操作 `($a * $b) % $c` 未使用 GMP，中间结果超过 PHP_INT_MAX
- 真实案例：自定义 RSA 实现中，两个大质数相乘产生的中间结果溢出
- 审计要点：跟踪所有涉及乘法/加法的操作，检查是否可能溢出

**3. 位运算掩码不匹配**
- 关键特征：用位运算提取/构造密钥时，掩码值与实际数据位宽不对齐
- 真实案例：`$iv = $value & 0xFFFFFFFF` 在 64 位环境上丢失高 32 位数据
- 审计要点：验证掩码是否包含了所有必要的数据位

### 误报判断关键点

**1. 标准库操作不是漏洞**
- `hash_hmac('sha256', ...)` 内部虽然涉及复杂运算，但 PHP 已处理溢出，审计时无需关注内部细节
- 区分：自定义实现 vs 调用标准库

**2. 控制流无法到达的溢出**
- 代码虽存在潜在溢出，但输入验证确保不会发生
- 示例：`$key = rand(1, 100); $hash = $key * 1000;` 永远不会溢出
- 审计检查：确认输入约束是否足够强

**3. 溢出不影响安全性的情况**
- 用作非密钥部分（如日志时间戳）的整数溢出
- 溢出值经过标准库处理后恢复（如 base64 编码）
- 关键审计：确认溢出的整数是否进入密码学关键路径

### 快速判断流程

| 现象 | 可能性 | 验证方法 |
|------|--------|---------|
| 大整数运算未用 GMP | 高风险 | 检查是否处理 2^31+ 的数值 |
| random_int 参数非字面量 | 中风险 | 跟踪参数来源，验证上下限 |
| 位运算用于密钥提取 | 高风险 | 验证掩码是否完整、数据是否丢失 |
| 自定义哈希实现 | 高风险 | 检查每个算术操作，是否有溢出保护 |
| 使用 password_hash/hash_hmac | 低风险 | 仅验证调用方式，无需深入 |

### 常见陷阱与修正建议

- **陷阱**：认为所有大整数运算都溢出——需确认溢出是否影响密钥安全性
- **陷阱**：忽视平台差异——32 位和 64 位 PHP 的 PHP_INT_MAX 不同，需验证代码跨平台行为
- **陷阱**：混淆算术溢出和数据丢失——溢出后的值经过恢复可能安全，但数据丢失是不可逆的

### 审计优先级建议

1. **必审**：自定义加密算法中的所有乘法、位运算、模运算
2. **必审**：random_int/mt_rand 的参数来源和范围
3. **优先**：GMP 函数的使用情况（使用表示已处理）
4. **快速检查**：是否存在密码学审计注释或安全文档

## Low risk

- 使用 PHP 标准密码学函数（`password_hash`、`hash_hmac` 等）
- 避免自定义加密/哈希算法
- 使用 GMP 扩展处理大整数
- 密码学代码经过专业审计
- 所有参数经过严格范围验证
