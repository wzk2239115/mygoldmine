# Move_PriceBasedFeeJump

**漏洞类型**：基于价格的费率跳变  
**影响范围**：Move生态（Sui、Aptos等）资源绑定型经济模型、动态费率调整、资产铸造配额  
**核心风险**：费率直接跟随外部价格剧烈波动，无平滑机制导致用户体验差，可能引发套利攻击或交易失败

---

## Details

**典型代码模式**：
```move
public fun calculate_fee(price: u64, amount: u64): u64 {
    // 费率直接等于价格比例，无平滑处理
    let fee_rate = price / 1000;  // 价格每1000单位对应1%费率
    return amount * fee_rate / 10000;
}

public entry fun update_fee_from_oracle(admin: &signer) {
    let price = oracle::get_price<USDT>();  // 直接读取预言机价格
    let config = borrow_global_mut<Config>(@protocol);
    config.fee_rate = price / 1000;  // 价格跳变导致费率瞬间变化
}

public fun get_dynamic_fee(): u64 acquires Config {
    let config = borrow_global<Config>(@protocol);
    let current_price = price_oracle::read<TOKEN>();
    // 缺失：平滑算法（EMA、移动平均、时间加权）
    return current_price * config.fee_multiplier / 10000;
}
```

**快速定位核心操作** [审计等级: **L1 - L2**]：
- **L1关键词扫描**：搜索 `oracle::`、`price::`、`fee_rate`、`calculate_fee`、`get_price`、`update_fee`、`dynamic_fee`
- **L2跳读验证**：定位费率计算函数，检查是否直接使用外部价格数据（无中间变量、无历史值缓存、无平滑计算逻辑）
- **L2跳读检查**：追踪价格更新函数调用链，确认更新频率（是否每个区块/每笔交易都重新读取价格）

**快速定位保护机制** [审计等级: **L2 - L3**]：
- **L2跳读检查**：查找是否存在平滑机制相关常量（`EMA_ALPHA`、`SMOOTHING_FACTOR`、`MAX_CHANGE_PER_BLOCK`）
- **L3逐行审计**：检查费率计算是否使用历史值（`last_fee_rate`、`fee_history`数组），是否存在变化率限制（`assert!(new_rate - old_rate <= MAX_DELTA)`）
- **L3逐行审计**：验证是否存在时间加权或移动平均逻辑（`weighted_average`、`exponential_moving_average`函数调用）
- **L4跨模块追踪**：检查预言机模块是否有价格异常检测（价格变化超过阈值时暂停更新或使用备用价格源）
- **关键缺陷信号**：费率计算函数直接返回 `price * multiplier`，无任何缓冲或平滑处理

## Classify

**归类为漏洞**：
- 费率直接等于或线性依赖外部价格，且价格更新无频率限制（每个区块/每笔交易都重新计算）
- 价格剧烈波动（如闪崩/闪涨）导致费率瞬间变化超过50%，用户无法预期交易成本
- 费率变化无上限约束，极端价格下费率可能超过100%或为负数，导致经济模型崩溃
- 存在套利空间：费率跳变滞后于价格变化，攻击者可利用时间差进行无风险套利

**归类为误报**：
- 费率虽基于价格，但存在硬性上限（如费率始终在0.1%-5%之间），价格波动不影响费率范围
- 价格更新需经过治理投票或时间锁（>24小时），无法瞬间跳变
- 费率计算使用链上时间加权平均价格（TWAP），已内置平滑机制
- 费率仅用于非关键功能（如推荐奖励系数），不影响核心交易手续费

**归类为代码异味**：
- 存在平滑机制但参数设置不合理（如EMA衰减因子过大，费率响应过于迟钝）
- 费率变化有上限但上限值过高（如单次变化允许50%），仍可能导致用户体验问题
- 平滑逻辑存在但仅在特定条件下生效（如仅在价格变化>10%时启用），小幅度频繁波动仍无保护
- 代码注释说明"待实现平滑机制"或存在TODO标记

---

## Low risk

**符合以下条件可评为低风险**：
1. **价格源稳定可靠**：使用多个预言机聚合（如Chainlink多节点取中位数），且价格更新有最小时间间隔（>1小时）
2. **费率影响范围有限**：费率仅影响非核心功能（如NFT铸造手续费），不影响主要交易对或质押奖励
3. **存在软性保护**：虽无代码级平滑，但价格源本身有异常检测（价格变化>20%时暂停更新），且历史数据显示价格波动极小
4. **用户可规避**：费率变化前有链上事件通知，用户可在费率不利时延迟交易，且协议提供费率锁定功能（用户可选择固定费率）
5. **经济模型容错**：费率变化导致的额外成本由协议金库承担，不转嫁给用户，且金库资金充足（>6个月运营成本）
6. **测试阶段**：协议处于测试网或早期主网阶段（<3个月），用户量小且资产规模有限，费率跳变影响可控

**不应降级为低风险的情况**：
- 声称"价格源可信"作为风险缓解措施（预言机可能被攻击或价格异常）
- 依赖链外监控或社区警报（无法阻止原子攻击或闪崩场景下的费率跳变）
- 费率影响核心交易对但仅通过文档说明"建议在价格稳定时交易"（用户无法强制执行）
- 存在平滑机制但仅在价格变化超过阈值时启用，小幅度频繁波动仍无保护
