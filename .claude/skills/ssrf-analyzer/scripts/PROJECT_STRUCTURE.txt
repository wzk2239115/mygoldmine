                            USAGE EXAMPLES
================================================================================

# Basic scanning
$ python cli.py --lang php /path/to/code

# JSON output
$ python cli.py --lang python --output json /path/to/code

# SARIF output
$ python cli.py --lang javascript --output sarif /path/to/code

# Multiple formats
$ python cli.py --lang php --output both \
    --json-out report.json \
    --sarif-out report.sarif \
    /path/to/code

$ python cli.py --help

$ python verify_structure.py

$ python QUICKREF.py

  2. Create languages/newlang/queries/sinks.scm
