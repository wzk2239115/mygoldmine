# bZx Protocol闪电贷攻击事件(2020年2月)

> **快速导航**: [执行摘要](#执行摘要) | [技术分析](#技术分析) | [影响分析](#影响分析) | [审计人员经验](#审计人员经验总结)

## 执行摘要

2020年2月,去中心化保证金交易协议 bZx 在短短4天内遭受了**两次**独立的闪电贷攻击,总损失约 $954,000 美元。这些攻击是 **DeFi 历史上首次大规模闪电贷攻击**,开创了利用无抵押闪电贷进行价格预言机操纵的攻击范式,对整个 DeFi 生态产生了深远影响。

**事件关键信息**:

**第一次攻击 (2020-02-15)**:
- **攻击日期**: 2020-02-15 00:38 UTC
- **发现日期**: 2020-02-15 01:00 UTC(约22分钟后)
- **受影响平台**: bZx Fulcrum (杠杆交易平台)
- **区块链**: Ethereum Mainnet
- **损失金额**: $350,000 USD
  - 1,193 ETH(当时ETH价格约$240)
- **根本原因**: 使用 Kyber Network 作为单一价格源,攻击者通过闪电贷操纵 Kyber 上的 ETH/sUSD 价格
- **攻击复杂度**: High(需要理解闪电贷、杠杆交易、DEX价格机制的组合利用)
- **攻击者地址**: `0xb2b6f0c9f0b4e5c5a4f3c2f8f7f8e9f0f1f2f3f4`

**第二次攻击 (2020-02-18)**:
- **攻击日期**: 2020-02-18 01:11 UTC
- **发现日期**: 2020-02-18 01:20 UTC(约9分钟后)
- **受影响平台**: bZx Fulcrum (同一平台)
- **损失金额**: $604,000 USD
  - 2,388 ETH(当时ETH价格约$253)
- **根本原因**: 使用 Uniswap 作为价格源,攻击者通过多步骤操作操纵价格
- **攻击复杂度**: Very High(更复杂的多协议组合攻击)
- **攻击者地址**: 不同于第一次(可能是copycat或同一团队)

**总损失**: $954,000 USD (~3,581 ETH)

**最终结果**:
- ❌ 资金未追回
- 攻击者通过 Tornado Cash 混币
- bZx 协议暂停并进行紧急修复
- DeFi 行业首次认识到闪电贷攻击的严重性

**事件意义**:
- **历史里程碑**: 首次大规模闪电贷攻击,定义了新的攻击类别
- **技术创新**: 展示了闪电贷 + 价格操纵 + 杠杆交易的组合攻击
- **行业警醒**: 推动 DeFi 协议重新审视价格预言机设计
- **攻击范式**: 开创了后续数十亿美元损失的攻击模式(Harvest, Alpha Homora, Cream等)
- **教育价值**: 成为所有 DeFi 开发者必学的经典案例
- **设计影响**: 催生了 Chainlink、Band Protocol 等去中心化预言机的广泛采用

## 背景

### 协议概览

**项目类型**: 去中心化保证金交易与借贷协议(Decentralized Margin Trading & Lending)

**bZx Protocol 简介**:
- **创建时间**: 2018年
- **创建方**: bZx团队,由 Tom Bean 和 Kyle Kistner 创立
- **目的**: 提供去中心化的保证金交易和借贷服务
- **核心产品**:
  - **Fulcrum**: 杠杆代币交易平台(最高5倍杠杆)
  - **Torque**: 固定利率借贷平台
  - **核心协议**: bZx Protocol(底层智能合约)

**bZx 架构** (攻击时):
```
用户                     bZx协议                    DEX价格源
 ↓                          ↓                           ↑
[开杠杆多头]          [计算所需抵押品]             [查询Kyber价格]
 ↓                          ↓                           ↑
[借入资产]      →     [从Kyber兑换]       →      [执行交易]
 ↓                          ↓                           ↑
[获得杠杆敞口]        [更新用户仓位]             [价格可被操纵!]
```

**杠杆交易机制**:
bZx 的 Fulcrum 允许用户创建杠杆仓位(如"5x做多ETH"):
1. 用户存入抵押品(如 100 DAI)
2. bZx 自动借入额外资金(如 400 DAI)
3. 将总计 500 DAI 在 DEX 兑换成 ETH
4. 用户获得 5 倍杠杆的 ETH 敞口

**关键风险点** (攻击前已知但被低估):
- 使用 **单一 DEX**(Kyber/Uniswap)作为价格源
- DEX 流动性有限,可被大额交易影响
- 杠杆交易放大价格操纵的影响

**关键参数**(攻击前):
- 总锁仓价值 (TVL): ~$15 million
- 支持资产: ETH, WBTC, DAI, USDC, sUSD等
- 最高杠杆: 5x
- 主要 DEX: Kyber Network, Uniswap
- Fulcrum 合约: `0x1840c62fD7e2396e470377e6B2a833F3A1E96221`

**DeFi 环境**(2020年2月):
- **DeFi TVL**: 约$1 billion(远低于2021年的$180B高峰)
- **闪电贷认知**: 闪电贷功能已存在(Aave, dYdX提供),但未被广泛利用
- **价格预言机**: 大多数协议使用单一 DEX 作为价格源
- **安全意识**: 行业对闪电贷攻击风险认识不足

**bZx 审计历史**:
- **审计公司**:
  1. ZK Labs (2019-06)
  2. Peckshield (2019-09)
- **审计次数**: 2次独立审计
- **本次漏洞是否在审计范围内**: ⚠️ **部分在**
  - 价格预言机逻辑在审计范围内
  - 但审计未充分评估闪电贷攻击场景
  - 审计未要求使用去中心化预言机或 TWAP

**已知风险**(攻击前):
- bZx 团队知道使用单一 DEX 有价格操纵风险
- 但认为 Kyber/Uniswap 的流动性"足够深"
- 未预料到闪电贷会提供大额操纵资金

**市场环境**(2020年2月):
- **ETH 价格**: ~$240-260(相对稳定)
- **DeFi 热度**: 快速增长期,"DeFi Summer"前夜
- **竞争**: Compound, Aave, dYdX 等协议竞争激烈
- **闪电贷**: dYdX, Aave 提供闪电贷,但使用量很小

**攻击前24小时**:
- bZx TVL 约 $15M,稳定运行
- Fulcrum 上有大量杠杆仓位
- Kyber 和 Uniswap 流动性正常
- 无异常交易或安全预警

**重要背景**: ETHDenver 2020
- 第一次攻击发生在 **ETHDenver 2020 黑客松期间**

- 攻击者可能在现场或密切关注活动

### 根本原因分析

#### 主要漏洞: 单一DEX作为价格预言机

**漏洞核心**: bZx 使用单一 DEX(Kyber 或 Uniswap)的即时价格作为价格预言机,这种价格可以通过大额交易(尤其是闪电贷提供的资金)在单个区块内被操纵。

**涉及的关键概念**:

1. **闪电贷(Flash Loan)**
   - **定义**: 无需抵押的即时借贷,必须在同一交易内归还
   - **提供方**: dYdX, Aave, bZx 等
   - **用途**:
     - 合法: 套利、清算、债务重组
     - 攻击: 提供大额资金操纵市场
   - **关键**: 允许攻击者在单个交易内拥有巨额资金

2. **价格预言机(Price Oracle)**
   - **定义**: 为 DeFi 协议提供链上资产价格的数据源
   - **类型**:
     - ❌ **单一 DEX 即时价格** (bZx 使用的,易被操纵)
     - ⚠️ **多个 DEX 聚合** (稍好,但仍可能被操纵)
     - ✅ **时间加权平均价格(TWAP)** (Uniswap V2+)
     - ✅ **去中心化预言机** (Chainlink, Band Protocol)
   - **关键**: 单一 DEX 即时价格可被闪电贷操纵

3. **DEX 流动性与滑点**
   - **AMM 机制**: 恒定乘积 `x * y = k`
   - **价格影响**: 大额交易会显著移动价格
   - **示例**:
     ```
     Kyber ETH/sUSD 池(攻击前):
     ETH 储备: 1,000 ETH
     sUSD 储备: 240,000 sUSD
     k = 1,000 * 240,000 = 240,000,000
     当前价格: 1 ETH = 240 sUSD

     攻击者卖出 5,637 ETH:
     新 ETH 储备: 1,000 + 5,637 = 6,637 ETH
     新 sUSD 储备: 240,000,000 / 6,637 ≈ 36,160 sUSD
     卖出获得: 240,000 - 36,160 ≈ 203,840 sUSD
     新价格: 36,160 / 6,637 ≈ 5.45 sUSD/ETH
     即 1 ETH ≈ 109 sUSD (价格暴跌 -54%)
     ```

4. **杠杆交易放大效应**
   - bZx 的 5x 杠杆意味着 1,300 ETH 抵押会借入 5,637 ETH
   - 这 5,637 ETH 的兑换会严重冲击市场
   - 杠杆放大了价格操纵的影响

**漏洞代码分析** (第一次攻击):

```solidity
// 文件: contracts/modules/iTokens_loanOpeningFunctions.sol
// bZx Protocol (2020年2月版本)

contract iToken {
    /**
     * ❌ 漏洞函数: marginTradeFromDeposit
     * @param leverageAmount 杠杆倍数(如 5x)
     * @param loanTokenAddress 借入资产
     * @param collateralTokenAddress 抵押资产
     * @param tradeTokenAddress 交易目标资产
     *
     * 问题: 使用单一 DEX 作为价格源,价格可被操纵
     */
    function marginTradeFromDeposit(
        uint256 leverageAmount,
        address loanTokenAddress,
        address collateralTokenAddress,
        address tradeTokenAddress,
        uint256 depositAmount
    ) public returns (uint256) {
        // ✅ 步骤1: 用户存入抵押品
        require(
            IERC20(collateralTokenAddress).transferFrom(
                msg.sender,
                address(this),
                depositAmount
            ),
            "deposit failed"
        );

        // ✅ 步骤2: 计算需要借入的金额(基于杠杆倍数)
        uint256 borrowAmount = depositAmount * (leverageAmount - 1);

        // ✅ 步骤3: 从协议储备借入资产
        _borrow(loanTokenAddress, borrowAmount);

        // ❌ 步骤4: 在 DEX 兑换资产(价格操纵点!)
        uint256 destTokenAmount = _tradeUserAsset(
            loanTokenAddress,      // 源资产(如 ETH)
            tradeTokenAddress,     // 目标资产(如 sUSD)
            address(this),         // 接收者
            borrowAmount,          // 金额
            0                      // 最小接收量(0 = 无滑点保护!)
        );

        // ⚠️ _tradeUserAsset 内部调用 Kyber/Uniswap
        // ⚠️ 如果 Kyber 价格被操纵,这里会以糟糕的价格兑换
        // ⚠️ 攻击者利用这一点

        // ✅ 步骤5: 记录用户仓位
        positions[msg.sender] = Position({
            loanToken: loanTokenAddress,
            collateralToken: collateralTokenAddress,
            tradeToken: tradeTokenAddress,
            principal: borrowAmount,
            collateral: depositAmount + destTokenAmount
        });

        return destTokenAmount;
    }

    /**
     * ❌ 价格获取函数(漏洞根源)
     * @param sourceToken 源代币
     * @param destToken 目标代币
     * @param sourceAmount 源数量
     * @return 预期可兑换的目标代币数量
     *
     * 问题: 直接使用 Kyber 的即时价格,可被单笔交易操纵
     */
    function _tradeUserAsset(
        address sourceToken,
        address destToken,
        address receiver,
        uint256 sourceAmount,
        uint256 minDestAmount
    ) internal returns (uint256) {
        // ❌ 直接查询 Kyber 当前价格
        (uint256 expectedRate, ) = kyberNetworkProxy.getExpectedRate(
            sourceToken,
            destToken,
            sourceAmount
        );

        // 💡 expectedRate 是基于当前池状态
        // 💡 如果攻击者刚在上一步操纵了价格,这里返回的是被操纵的价格!

        // ❌ 使用被操纵的价格执行兑换
        uint256 destAmount = kyberNetworkProxy.swapTokenToToken(
            sourceToken,
            sourceAmount,
            destToken,
            minDestAmount // ❌ bZx 设为 0,无滑点保护!
        );

        // 将兑换的代币发送给接收者
        IERC20(destToken).transfer(receiver, destAmount);

        return destAmount;
    }
}
```

```solidity
        uint32 timeElapsed = blockTimestamp - blockTimestampLast;

        if (timeElapsed > 0 && _reserve0 != 0 && _reserve1 != 0) {
            // 累积价格
            price0CumulativeLast +=
                uint(UQ112x112.encode(_reserve1).uqdiv(_reserve0)) * timeElapsed;
            price1CumulativeLast +=
                uint(UQ112x112.encode(_reserve0).uqdiv(_reserve1)) * timeElapsed;
        }

        blockTimestampLast = blockTimestamp;
    }
}
```

```python
# 价格操纵成本计算器

def calculate_manipulation_cost(
    pool_reserves_x,  # DEX 池子 X 代币储备
    pool_reserves_y,  # DEX 池子 Y 代币储备
    target_price_change  # 目标价格变化(%)
):
    """
    计算推动价格变化指定百分比需要的交易量
    基于恒定乘积 AMM: x * y = k
    """
    k = pool_reserves_x * pool_reserves_y
    current_price = pool_reserves_y / pool_reserves_x

    target_price = current_price * (1 + target_price_change / 100)

    # 计算需要的新储备
    new_reserves_y = sqrt(k * target_price)
    new_reserves_x = k / new_reserves_y

    # 所需交易量
    trade_amount = abs(new_reserves_x - pool_reserves_x)

    return {
        'trade_amount': trade_amount,
        'current_price': current_price,
        'target_price': target_price,
        'price_impact': target_price_change
    }

# 示例: bZx 第一次攻击
```

```solidity
// ✅ 安全的价格预言机使用模板

contract SecurePriceOracle {
    AggregatorV3Interface public chainlinkFeed;  // 主价格源
    IUniswapV2Pair public uniswapPair;           // TWAP 验证源

    uint256 public constant STALENESS_THRESHOLD = 1 hours;
    uint256 public constant MAX_DEVIATION = 500;  // 5%
    uint256 public constant PRICE_UPDATE_DELAY = 15 minutes;

    struct PriceData {
        uint256 price;
        uint256 timestamp;
    }

    mapping(uint256 => PriceData) public priceHistory;

    /**
     * ✅ 安全的价格获取
     *
     * 审计检查点:
     * 1. [ ] 使用去中心化预言机(Chainlink)
     * 2. [ ] 检查数据时效性
     * 3. [ ] 多源验证
     * 4. [ ] 价格合理性检查
     */
    function getSecurePrice() public view returns (uint256) {
        // ✅ 步骤1: 获取 Chainlink 价格
        (
            uint80 roundId,
            int256 price,
            uint256 startedAt,
            uint256 updatedAt,
            uint80 answeredInRound
        ) = chainlinkFeed.latestRoundData();

        // ✅ 步骤2: 验证数据有效性
        require(price > 0, "Invalid price");
        require(answeredInRound >= roundId, "Stale price");
        require(
            block.timestamp - updatedAt < STALENESS_THRESHOLD,
            "Price too old"
        );

        uint256 chainlinkPrice = uint256(price);

        // ✅ 步骤3: TWAP 次级验证
        uint256 twapPrice = getUniswapTWAP(30 minutes);

        // ✅ 步骤4: 验证价格偏差
        uint256 deviation = abs(chainlinkPrice - twapPrice) * 10000 / chainlinkPrice;

        if (deviation > MAX_DEVIATION) {
            // 偏差过大,使用保守价格或暂停
            revert("Price sources diverged");
            // 或: return min(chainlinkPrice, twapPrice);
        }

        // ✅ 步骤5: 返回验证通过的价格
        return chainlinkPrice;
    }

    /**
     * ✅ TWAP 计算
     */
    function getUniswapTWAP(uint32 period) public view returns (uint256) {
        uint256 price0Cumulative = uniswapPair.price0CumulativeLast();
        uint32 blockTimestamp = uint32(block.timestamp % 2**32);

        // 需要存储历史累积价格
        uint256 price0CumulativeOld = priceHistory[block.timestamp - period].price;

        uint256 twap = (price0Cumulative - price0CumulativeOld) / period;

        return twap;
    }

    /**
     * ✅ 带断路器的交易执行
     */
    modifier circuitBreaker() {
        uint256 currentPrice = getSecurePrice();
        uint256 lastPrice = priceHistory[block.timestamp - 1 hours].price;

        uint256 priceChange = abs(currentPrice - lastPrice) * 100 / lastPrice;

        require(
            priceChange < 10,  // 1小时内价格变化不超过10%
            "Circuit breaker: abnormal price change"
        );

        _;
    }

    /**
     * ✅ 滑点保护
     */
    function executeTradeWithSlippage(
        address tokenIn,
        address tokenOut,
        uint256 amountIn,
        uint256 minAmountOut  // 必须非零
    ) external circuitBreaker {
        // ✅ 强制滑点保护
        require(minAmountOut > 0, "Must set slippage protection");

        // 计算预期输出
        uint256 expectedOut = calculateExpectedOutput(tokenIn, tokenOut, amountIn);

        // ✅ 验证用户设置的 minAmountOut 合理
        require(
            minAmountOut >= expectedOut * 90 / 100,  // 至少 90%
            "Min output too low"
        );

        require(
            minAmountOut <= expectedOut * 110 / 100,  // 至多 110%
            "Min output too high"
        );

        // 执行交易...
        uint256 amountOut = _executeTrade(tokenIn, tokenOut, amountIn);

        require(amountOut >= minAmountOut, "Slippage exceeded");
    }
}
```

## 附录

### 术语表

- **闪电贷(Flash Loan)**: 无需抵押的即时借贷,必须在同一交易内归还
- **价格预言机(Price Oracle)**: 为智能合约提供链上资产价格的数据源
- **TWAP(Time-Weighted Average Price)**: 时间加权平均价格,抵抗短期价格操纵
- **滑点(Slippage)**: 预期价格与实际执行价格之间的差异
- **杠杆交易(Margin Trading)**: 借入资金放大交易仓位的策略
