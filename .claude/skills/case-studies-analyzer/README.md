## 项目简介

### 什么是案例研究数据库？

本数据库是 blockchain_goldmine 漏洞知识库的重要扩展，提供：

✅ **真实攻击案例** - 从 The DAO (2016) 到最新的 DeFi 攻击
✅ **技术深度分析** - 漏洞代码、攻击流程、根因剖析
✅ **审计实战指导** - 检测策略、检查清单、误报识别
✅ **历史背景关联** - 了解漏洞在真实世界中的表现形式
✅ **行业标准映射** - 链接到 CWE/SWC/CVE 标准（规划中）

### 与漏洞模式文档的关系

```
漏洞模式文档 (reentrancy/Solidity_WithdrawReentrancy.md)
    ↓
  理论模式
    ↓
    ↕ (双向链接)
    ↓
  真实案例
    ↓
```

- **模式文档**: 教你"什么是重入漏洞"、"如何检测"

## 如何使用

### 面向审计人员

#### 场景 1: 学习特定漏洞类型

1. 访问 [漏洞类别浏览](#按漏洞类别浏览)
2. 选择感兴趣的类别（如"重入攻击"）
3. 阅读该类别的案例研究
4. 参考"审计人员经验总结"章节
5. 应用检查清单到实际审计工作

#### 场景 2: 准备审计特定协议类型

1. 确定协议类型（如借贷协议）
2. 搜索相关案例（Ctrl+F "Lending"）
3. 研究历史攻击模式
4. 整理审计重点和风险点
5. 定制化检查清单

#### 场景 3: 验证漏洞发现

当您在审计中发现潜在漏洞时：

1. 查找类似历史案例
2. 对比攻击条件和影响
3. 评估严重性（参考历史损失）
4. 在报告中引用案例作为证据
5. 提供参考修复方案

### 面向开发者

#### 场景 1: 学习安全最佳实践

1. 选择您使用的编程语言（Solidity/Rust/Move）
2. 阅读该语言的典型攻击案例
3. 查看"修复代码"示例
4. 将安全模式应用到您的代码
5. 参考测试用例编写安全测试

#### 场景 2: 事件响应参考

如果您的协议遭受攻击：

1. 查找类似攻击案例
2. 参考"响应与恢复"章节
3. 学习有效的应急措施
4. 了解资金追回可能性
5. 准备用户沟通策略

### 面向研究者

#### 数据分析

- 使用统计数据进行趋势研究
- 分析不同类型漏洞的损失分布
- 研究审计覆盖率与安全性的关系
