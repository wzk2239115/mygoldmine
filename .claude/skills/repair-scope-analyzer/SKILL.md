# 修复作用域分析

## 仓库专属

满足以下任一情况时，只生成仓库专属修复：

- 证据只来自一个项目，或根因依赖项目特有入口、配置、文件和部署方式。
- 尚未排除其他项目中的反例。
- 规则必须引用当前项目文件或验证配方才能准确表达。

## 共享

只有同时具备以下条件才生成共享修复：

- 至少两个项目具有相同根因和可信证据，而不是只有相同漏洞类别或危险函数。
- 能脱离单一项目文件路径，准确说明共同根因、适用前提和反证。
- 有未参与来源训练的项目可用于独立候选重跑。

## 失效检查

代码、默认配置、信任边界或部署形态变化后，旧规则必须重新验证。共享与项目规则冲突时不得自动覆盖，交给当前代码证据和后续验证判断。
