# PHP_PaymentState_DirectModification

## Details

**核心漏洞特征**：PHP应用中支付状态可被直接修改，无状态转换验证，允许订单从任意状态转换。

**代码示例定位**：查找状态修改代码，关键词包括 `$order->status =`, `UPDATE orders SET status`, `$_POST['status']` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索 `$order->status = $_POST['status']` - 检查直接赋值
- 搜索 `UPDATE orders SET status = '$status'` - 检查SQL更新
- 搜索 `$_POST` 或 `$_REQUEST` 中的status - 检查客户端控制
- 搜索状态常量或enum - 检查是否有状态定义

**快速定位保护机制**（L2: 跳读）：
- 检查是否有状态转换白名单
- 检查是否验证当前状态
- 检查是否使用数据库约束
- 检查是否有状态转换日志

## Classify

**漏洞判定标准**：
- 状态直接从客户端接收 → **漏洞**
- 无状态转换验证 → **漏洞**
- 允许任意状态转换 → **漏洞**
- 无状态转换日志 → **漏洞**

**误报情况**：
- 有状态转换白名单验证 → 低风险
- 数据库约束限制转换 → 低风险
- 状态值为常量非字符串 → 低风险

**代码异味**：
- 虽有验证但逻辑不完整 → 审计
- 多处状态修改代码 → 审计

## Low risk

**低风险评级条件**：
1. **转换白名单**：严格定义允许的状态转换
2. **状态定义**：使用常量或enum而非字符串
3. **验证强制**：所有修改前验证转换合法性
4. **数据库保护**：约束限制非法转换
5. **审计日志**：所有转换都记录
