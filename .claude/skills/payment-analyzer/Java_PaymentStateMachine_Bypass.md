# Java_PaymentStateMachine_Bypass

## Details

**核心漏洞特征**：Java应用中支付状态机设计有缺陷，允许跳过某些必要的中间状态进行支付。

**代码示例定位**：查找状态转换代码，关键词包括 `transition()`, `status`, `state_machine`, `setState()` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索状态转换函数 - 检查转换规则
- 搜索状态定义 - 检查是否完整
- 搜索多个if分支 - 检查是否覆盖所有情况
- 搜索UPDATE操作 - 检查WHERE条件

**快速定位保护机制**（L2: 跳读）：
- 检查是否有明确的转换白名单
- 检查是否有必要的中间状态
- 检查是否所有转换都被定义
- 检查是否无法跳过状态

## Classify

**漏洞判定标准**：
- 转换不受限制 → **漏洞**
- 可跳过必要状态 → **漏洞**
- 转换检查不完整 → **漏洞**
- 无状态机实现 → **漏洞**

**误报情况**：
- 有明确的转换白名单 → 低风险
- 所有转换都检查 → 低风险
- 无法跳过中间状态 → 低风险

**代码异味**：
- 虽有白名单但逻辑有漏 → 审计
- 多处状态检查 → 审计

## Low risk

**低风险评级条件**：
1. **白名单定义**：明确定义所有允许的转换
2. **转换验证**：所有转换都验证当前状态
3. **必要状态**：无法跳过必要的中间状态
4. **数据库约束**：约束限制非法转换
5. **审计日志**：所有转换都记录
