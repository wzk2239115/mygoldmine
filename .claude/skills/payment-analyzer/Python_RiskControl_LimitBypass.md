# Python_RiskControl_LimitBypass

## Details

**核心漏洞特征**：Python应用中风控限制可被绕过，攻击者通过代理、多账户、或其他手段绕过风控。

**代码示例定位**：查找风控代码，关键词包括 `limit`, `check_risk`, `rate_limit`, `frequency` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索风控检查函数 - 检查限制逻辑
- 搜索request.remote_addr - 检查IP识别
- 搜索user_id - 检查用户识别
- 搜索绕过条件 - 检查是否有例外

**快速定位保护机制**（L2: 跳读）：
- 检查是否使用多维度限制（IP、用户、设备）
- 检查是否有异常检测
- 检查是否验证代理IP
- 检查是否有动态调整

## Classify

**漏洞判定标准**：
- 单维度限制易绕过 → **漏洞**
- 无代理IP检测 → **漏洞**
- 限制逻辑有漏洞 → **漏洞**
- 限制标准太宽松 → **漏洞**

**误报情况**：
- 多维度限制 → 低风险
- 有异常检测 → 低风险
- 动态调整 → 低风险

**代码异味**：
- 虽有限制但维度不足 → 审计
- 限制标准不清 → 审计

## Low risk

**低风险评级条件**：
1. **多维度限制**：按IP、用户、设备、指纹多维限制
2. **代理识别**：识别代理和VPN
3. **异常检测**：检测异常行为模式
4. **动态调整**：根据风险动态调整限制
5. **日志告警**：触发限制有告警和日志
