# Python_Amount_FloatPrecision

## Details

**核心漏洞特征**：Python支付应用使用浮点数表示金额，导致精度丧失和计算错误。

**代码示例定位**：查找金额处理代码，关键词包括 `amount`, `price`, `balance`, `float`, `Decimal` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索 `amount: float` 或 `float(amount)` - 检查是否使用浮点
- 搜索 `0.1 +` 或 `0.2 +` - 检查浮点计算
- 搜索 `from decimal import Decimal` - 检查是否使用Decimal
- 搜索 `round()` 函数 - 检查精度处理

**快速定位保护机制**（L2: 跳读）：
- 检查是否使用Decimal库
- 检查是否使用整数表示（分为单位）
- 检查金额验证和转换逻辑
- 检查数据库字段类型

## Classify

**漏洞判定标准**：
- 使用float表示金额 → **漏洞**
- 浮点计算未考虑精度 → **漏洞**
- round()处理精度 → **漏洞**
- 数据库使用FLOAT类型存储金额 → **漏洞**

**误报情况**：
- 使用Decimal库 → 低风险
- 使用整数表示（分为单位） → 低风险
- 数据库DECIMAL类型 → 低风险

**代码异味**：
- 虽用Decimal但转换逻辑有问题 → 审计
- 混合使用float和Decimal → 审计

## Low risk

**低风险评级条件**：
1. **类型选择**：使用Decimal或整数表示金额
2. **单位统一**：全局使用分为单位的整数
3. **转换正确**：输入输出转换无精度丧失
4. **数据库类型**：使用DECIMAL而非FLOAT
5. **测试覆盖**：金额计算有单元测试
