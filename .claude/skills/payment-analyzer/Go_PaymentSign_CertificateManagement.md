# Go_PaymentSign_CertificateManagement

## Details

**核心漏洞特征**：Go应用中支付签名证书管理不当，证书过期未更新、存储位置不安全、或使用弱算法签名。

**代码示例定位**：查找证书加载代码，关键词包括 `tls.LoadX509KeyPair`, `certificate`, `cert`, `private.key` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索 `tls.LoadX509KeyPair()` - 检查证书加载
- 搜索证书文件路径 `.crt`, `.key`, `.pem` - 检查存储位置
- 搜索 `x509.Certificate` - 检查证书验证
- 搜索签名算法 `SHA1`, `SHA256` - 检查算法强度

**快速定位保护机制**（L3: 逐行读）：
- 检查证书是否存储在Web根目录
- 检查证书文件权限（应为600）
- 检查是否验证证书有效期
- 检查是否有证书轮换机制

## Classify

**漏洞判定标准**：
- 证书存储在可访问位置 → **漏洞**
- 使用已弃用的签名算法（SHA1） → **漏洞**
- 无证书有效期验证 → **漏洞**
- 证书文件权限过宽 → **漏洞**

**误报情况**：
- 证书存储在安全位置 → 低风险
- 使用SHA256或更强算法 → 低风险
- 有证书有效期检查 → 低风险

**代码异味**：
- 虽有有效期检查但不强制更新 → 审计
- 多个证书无版本管理 → 审计

## Low risk

**低风险评级条件**：
1. **存储安全**：证书存储在Web根目录外
2. **文件权限**：证书文件权限为600或更严格
3. **算法强度**：使用SHA256或更强的签名算法
4. **有效期检查**：应用启动时验证证书未过期
5. **轮换机制**：有证书轮换和更新流程
