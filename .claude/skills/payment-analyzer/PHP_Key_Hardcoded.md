# PHP_Key_Hardcoded

## Details

**核心漏洞特征**：PHP代码中将支付密钥、API密钥、签名密钥直接硬编码为字符串常量或配置数组，密钥存储在版本控制系统、编译文件或代码注释中，导致密钥泄露风险极高。

**代码示例定位**：查找密钥定义位置（文件级别常量、配置文件、类属性），关键词包括 `$key`, `'secret'`, `'apiKey'`, `define()`, `const` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索 `define('SECRET_KEY', '...')` 或 `$secret = '...'` - 硬编码密钥定义
- 搜索 `$apiKey = 'sk_live_...'` 或 `$merchantKey = '...'` - 支付服务密钥
- 搜索 `md5()`, `hash_hmac()` 等密钥参数传入 - 检查密钥来源
- 搜索 `.env.example`, `config.php` 等配置文件 - 检查是否有默认密钥

**快速定位保护机制**（L2: 跳读）：
- 检查是否使用环境变量（`$_ENV`, `getenv()`）或密钥管理系统（如AWS Secrets Manager、HashiCorp Vault）
- 检查是否有密钥存储在`.env`文件且`.env`在`.gitignore`中
- 检查密钥是否从外部密钥服务动态加载
- 检查是否有密钥轮换机制（定期更新和撤销）

## Classify

**漏洞判定标准**：
- 密钥以明文字符串形式出现在PHP代码中 → **漏洞**
- 密钥在配置数组或常量中硬编码 → **漏洞**
- 版本控制历史中存在密钥提交记录 → **漏洞**
- 生产环境密钥与开发环境密钥相同 → **漏洞**
- `.env.example` 或示例文件中包含真实密钥 → **漏洞**

**误报情况**：
- 公开密钥（如OAuth 2.0的client_id）硬编码 → 低风险
- 密钥通过环境变量或密钥管理系统加载 → 低风险
- 仅测试环境的演示密钥 → 低风险

**代码异味**：
- 密钥存储在注释或文档中 → 审计
- 密钥传递为函数参数但无加密通道 → 审计
- 多个应用共享一个密钥 → 审计

## Low risk

**低风险评级条件**：
1. **密钥外部化**：所有生产密钥通过环境变量、密钥管理系统或配置中心加载
2. **访问控制**：密钥文件（`.env`）和密钥管理系统有严格的访问权限限制
3. **版本控制隔离**：密钥文件在`.gitignore`中，版本历史中无密钥泄露
4. **密钥轮换**：密钥定期轮换（至少按季度），旧密钥及时撤销
5. **审计日志**：所有密钥访问和使用都有审计记录
