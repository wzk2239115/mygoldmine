# NodeJS_Callback_SignatureMissing

## Details

**核心漏洞特征**：NodeJS应用中缺少支付回调签名验证，任何人可伪造回调通知。

**代码示例定位**：查找回调处理代码，关键词包括 `/callback`, `/webhook`, `signature`, `verify` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索回调路由 - 检查是否有签名验证
- 搜索 `crypto.createHmac()` - 检查是否验证
- 搜索 `if (signature ===` - 检查验证逻辑
- 搜索请求体处理 - 检查是否验证签名

**快速定位保护机制**（L2: 跳读）：
- 检查是否使用HMAC-SHA256
- 检查是否验证所有参数
- 检查是否比对签名
- 检查是否验证失败拒绝

## Classify

**漏洞判定标准**：
- 无签名验证 → **漏洞**
- 签名验证不完整 → **漏洞**
- 使用弱算法（MD5） → **漏洞**
- 验证失败继续处理 → **漏洞**

**误报情况**：
- HMAC-SHA256验证 → 低风险
- 完整的参数验证 → 低风险
- 验证失败拒绝 → 低风险

**代码异味**：
- 虽有验证但算法弱 → 审计
- 验证逻辑分散 → 审计

## Low risk

**低风险评级条件**：
1. **算法选择**：使用HMAC-SHA256
2. **参数验证**：验证所有回调参数
3. **比对方式**：使用timing-safe比对
4. **失败处理**：验证失败立即拒绝
5. **日志记录**：验证失败有安全日志
