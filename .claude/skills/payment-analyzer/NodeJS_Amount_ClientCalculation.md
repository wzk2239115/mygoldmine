# NodeJS_Amount_ClientCalculation

## Details

**核心漏洞特征**：NodeJS应用中金额由客户端计算并上传，应用直接信任客户端计算结果，导致金额被篡改。

**代码示例定位**：查找金额处理代码，关键词包括 `req.body.amount`, `req.body.total`, `req.body.price` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索 `const amount = req.body.amount` - 检查是否直接使用客户端值
- 搜索 `INSERT INTO payments (amount)` - 检查是否直接存储
- 搜索计算逻辑 - 检查是否在服务端重新计算
- 搜索商品价格 - 检查是否从数据库获取

**快速定位保护机制**（L2: 跳读）：
- 检查是否从数据库查询商品价格
- 检查是否在服务端重新计算金额
- 检查金额是否与预期值比对
- 检查是否验证金额范围

## Classify

**漏洞判定标准**：
- 直接使用客户端金额 → **漏洞**
- 不验证金额正确性 → **漏洞**
- 无价格来源验证 → **漏洞**
- 无金额与商品的绑定验证 → **漏洞**

**误报情况**：
- 从数据库获取商品价格服务端计算 → 低风险
- 金额与预期值验证 → 低风险
- 有完整的金额检查 → 低风险

**代码异味**：
- 虽查询价格但未用于验证 → 审计
- 计算逻辑分散 → 审计

## Low risk

**低风险评级条件**：
1. **源头获取**：商品价格从数据库而非客户端
2. **服务端计算**：金额完全由服务端计算
3. **验证对比**：比对计算值与客户端上传值
4. **绑定验证**：金额与商品ID绑定验证
5. **异常拒绝**：金额不符拒绝请求
