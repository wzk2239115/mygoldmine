# C_Key_Management

## Details

**核心漏洞特征**：C应用中密钥管理不当，密钥存储不安全、访问无控制、或使用弱算法。

**代码示例定位**：查找密钥管理代码，关键词包括 `key`, `secret`, `password`, `load`, `store` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索密钥定义位置 - 检查是否硬编码
- 搜索文件操作 - 检查密钥存储位置
- 搜索权限设置 - 检查文件权限
- 搜索密钥使用处 - 检查是否暴露

**快速定位保护机制**（L2: 跳读）：
- 检查是否从环境变量或KMS加载
- 检查密钥文件权限
- 检查是否在内存中清零
- 检查是否有访问控制

## Classify

**漏洞判定标准**：
- 密钥硬编码 → **漏洞**
- 密钥存储在Web根目录 → **漏洞**
- 文件权限过宽 → **漏洞**
- 无访问控制 → **漏洞**

**误报情况**：
- 从环境变量或KMS加载 → 低风险
- 文件权限600或更严 → 低风险
- 有访问控制 → 低风险

**代码异味**：
- 虽有保护但不完整 → 审计
- 多处密钥副本 → 审计

## Low risk

**低风险评级条件**：
1. **外部化**：从环境变量或密钥管理系统加载
2. **文件权限**：密钥文件权限为600或更严
3. **访问控制**：有权限检查和审计
4. **内存清零**：使用后清零内存
5. **版本管理**：支持密钥轮换和版本控制
