# Rust_Key_RotationMissing

## Details

**核心漏洞特征**：Rust应用中密钥轮换机制缺失，密钥长期使用无更新，被破解后无法快速撤销。

**代码示例定位**：查找密钥管理代码，关键词包括 `load_key()`, `get_key()`, `version`, `rotation` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索密钥加载函数 - 检查是否支持多版本
- 搜索密钥初始化时间 - 检查是否有记录
- 搜索版本检查 - 检查是否支持轮换
- 搜索签名时的版本 - 检查是否记录密钥版本

**快速定位保护机制**（L2: 跳读）：
- 检查是否有密钥版本管理
- 检查是否支持并存多个密钥
- 检查是否有过期密钥清理机制
- 检查是否有轮换时间表

## Classify

**漏洞判定标准**：
- 无密钥版本管理 → **漏洞**
- 无轮换机制 → **漏洞**
- 无过期密钥清理 → **漏洞**
- 密钥永久有效 → **漏洞**

**误报情况**：
- 有版本管理和轮换计划 → 低风险
- 支持并存多个密钥 → 低风险
- 有清理机制 → 低风险

**代码异味**：
- 虽有版本但无轮换流程 → 审计
- 轮换时间不明确 → 审计

## Low risk

**低风险评级条件**：
1. **版本管理**：每个密钥有版本号
2. **并存支持**：可同时使用多个密钥版本
3. **轮换计划**：定期轮换密钥（至少年度）
4. **清理机制**：过期密钥有清理流程
5. **记录版本**：签名时记录使用的密钥版本
