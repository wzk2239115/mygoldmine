# Python_PaymentData_Encryption

## Details

**核心漏洞特征**：Python应用中敏感支付数据未加密存储或传输，或使用弱加密算法。

**代码示例定位**：查找数据存储和传输代码，关键词包括 `card_number`, `password`, `secret`, `encrypt`, `AES` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索 `card_number = ` - 检查是否明文存储
- 搜索 `requests.post()` - 检查是否HTTPS
- 搜索 `from cryptography import` - 检查是否使用加密库
- 搜索 `encrypt()` 或 `decrypt()` - 检查加密实现

**快速定位保护机制**（L2: 跳读）：
- 检查是否使用AES-256加密
- 检查是否有密钥管理
- 检查是否使用HTTPS传输
- 检查是否有IV/Salt生成

## Classify

**漏洞判定标准**：
- 敏感数据明文存储 → **漏洞**
- HTTP明文传输 → **漏洞**
- 使用弱加密算法（DES、MD5） → **漏洞**
- 无密钥管理 → **漏洞**

**误报情况**：
- AES-256加密存储 → 低风险
- HTTPS传输 → 低风险
- 正确的密钥管理 → 低风险

**代码异味**：
- 虽有加密但密钥硬编码 → 审计
- IV未随机生成 → 审计

## Low risk

**低风险评级条件**：
1. **加密算法**：使用AES-256-GCM
2. **密钥管理**：密钥存储在密钥管理系统
3. **传输加密**：使用HTTPS/TLS
4. **随机化**：IV和Salt随机生成
5. **数据脱敏**：数据库中不存储完整卡号
