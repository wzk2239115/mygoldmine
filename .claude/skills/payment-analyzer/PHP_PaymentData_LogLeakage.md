# PHP_PaymentData_LogLeakage

## Details

**核心漏洞特征**：PHP应用中敏感支付数据被记录到日志文件，包括卡号、密码、CVV等。

**代码示例定位**：查找日志代码，关键词包括 `error_log()`, `log()`, `syslog()`, `card_number` 等。

**快速定位核心操作**（L1: 关键词扫描）：
- 搜索 `error_log($_POST)` - 检查是否记录客户端数据
- 搜索 `var_dump($payment)` - 检查是否输出变量
- 搜索 `print_r()` - 检查是否打印敏感数据
- 搜索支付相关的日志调用 - 检查是否包含敏感字段

**快速定位保护机制**（L2: 跳读）：
- 检查是否masking或redacting敏感字段
- 检查是否仅记录非敏感字段
- 检查日志文件权限
- 检查日志存储位置

## Classify

**漏洞判定标准**：
- 日志记录卡号或密码 → **漏洞**
- var_dump或print_r输出敏感数据 → **漏洞**
- 异常堆栈跟踪包含敏感信息 → **漏洞**
- 日志文件权限过宽 → **漏洞**

**误报情况**：
- 敏感字段被masking → 低风险
- 仅记录交易ID → 低风险
- 日志权限严格 → 低风险

**代码异味**：
- 虽有masking但不完整 → 审计
- 某些路径未被保护 → 审计

## Low risk

**低风险评级条件**：
1. **字段掩码**：卡号记录为****1234
2. **选择记录**：仅记录交易ID、金额类别
3. **异常处理**：异常消息不包含敏感数据
4. **日志权限**：权限为600或更严格
5. **日志位置**：不存储在Web根目录
