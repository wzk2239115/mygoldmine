# GoldMine 实验数据快照

本目录提供论文写作可引用的**运行观测数据**，由服务器上已有的审计记录导出。每次提交是一份固定快照；正在运行的项目随后可能产生新记录。数据生成时间、源代码版本、文件哈希与表格行数见 `manifest.json`。

## 使用方式

从仓库根目录运行：

```bash
python3 scripts/experimental/export_paper_data.py --repo-root . --output data
```

导出器读取本机的 `runs/`、`rsi/stage-skills/cycles/` 和 `.runtime/state/token-usage/`，并查询本机界面服务中的项目与严格验证报告列表。这些运行记录没有完整纳入 Git；在别的机器上仅克隆 GitHub 仓库，**无法重新生成同一快照**。需要重现实验时，应另行保存源代码版本、目标项目版本、运行配置和原始记录。

## 文件说明

| 文件 | 每行代表什么 | 主要用途 |
| --- | --- | --- |
| `projects.csv` | 看板中的一个项目 | 固定本次项目集合，保留源代码版本和候选数 |
| `runs.csv` | 一次审计运行或恢复运行 | 比较运行状态、耗时与候选报告数量 |
| `workflow_stages.csv` | 一次工作流的一个阶段 | 查看八阶段执行状态；同一运行的重试需按工作流编号区分 |
| `cycles.csv` | 一个连续学习循环 | 查看循环状态、配置轮数与已记录轮数 |
| `cycle_rounds.csv` | 循环中的一条轮次记录 | 把轮次关联到运行和最后可见的工作流状态；记录为 `partial` 不表示轮次完成 |
| `stage_coverage.csv` | 一次运行的第二阶段读取观测 | 查看精确读取行数、累计精确读取行数、意图数量与未归因事件 |
| `rsi_rewards.csv` | 一次运行的评分记录 | 分别分析新增读取、报告信号及两项分数 |
| `token_usage.csv` | 同一项目、运行、阶段、模型和提供方的一组用量 | 分析可观测词元投入和缺失情况 |
| `verified_reports.csv` | 一份符合严格展示条件的报告 | 按时间和严重度分析报告出现情况；稳定哈希代替漏洞编号 |
| `manifest.json` | 整份快照 | 核对生成时间、源代码版本、表格行数和文件校验值 |

表格列名和状态值保持与导出源一致。空值表示来源未提供或无法可靠归属，并非数值零。特别地，`candidate_count`、`board_candidates` 都是候选问题计数；`reports_complete` 只表示该次审计报告文件完整，均不表示漏洞已验证。工作流的阶段状态与连续循环状态是不同层次的数据。

## 数据口径

- **项目集合**：按导出时看板显示的项目冻结。目标清单、界面项目元数据和实际运行目录数量不同，不能互相代替，也不能把所有登记项目写成已完成实验项目。
- **运行与轮次**：运行元数据、连续循环状态和八阶段工作流回执分别记录。一个项目可有多次运行、恢复和重试；这些不能直接相加为独立审计或已完成轮次。处于运行中的记录是截取时的状态。
- **读取覆盖与审计意图**：第二阶段的代码读取记录表示智能体实际读取到的文件和行区间。它没有全仓库可审计代码的固定分母，不能直接写成“代码覆盖率百分比”或“理解了这些代码”。没有关联成功的意图单独记为未归因，不能补成有效意图。
- **RSI 评分**：当前实现的两项评分为 `R = 0.01 × 新增风险加权读取行数 + 10 × 新增严格验证报告数`。风险行权重来自 Jev 优先级，权重为 `1 + priority`。评分与技能修改的关系仅属关联，不证明技能造成了收益。论文材料中的多项损失函数和配对对照实验是设计方案，不能当作已运行结果。
- **严格验证报告**：报告列表要求蓝队动态确认、红队证据核验、独立审核通过，并具备文生图插图及其证明。这比“已有蓝队确认”或“独立审核通过”都更窄，也不等于 CVE 数量。表格仅导出脱敏的索引和时间、严重度等元数据，不包含漏洞描述、利用步骤、附件或原始轨迹。
- **词元用量**：按项目、运行、阶段、模型和提供方口径分组。缺失字段与未知用量保留为缺失，不补零；不同提供方的缓存词元含义不能直接合并。历史未记录的调用无法回填，因此数据不代表完整账单。
- **效果结论**：这份快照是观察性数据。没有固定基线、相同预算和对照组时，不能由累计读取量或报告数推断 RSI 的因果增益，也不能直接声称“覆盖提升 200%”。

## 隐私与安全边界

本目录不收录原始模型对话、漏洞正文、复现脚本、附件内容、密钥或主机绝对路径。项目名、源代码版本和聚合统计仍可公开；未修复漏洞的技术细节保留在服务器受控记录中。

字段名使用英文以便分析；表格空值表示来源不存在、不可解析或该指标不适用，具体计数和数据质量标记见快照清单。论文中的数量应注明快照时间，并与本文的统计口径一起引用。
